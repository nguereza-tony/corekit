# CoreKit

[![Go Version](https://img.shields.io/badge/Go-1.25+-blue.svg)](https://golang.org)
[![License](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE)
[![PRs Welcome](https://img.shields.io/badge/PRs-welcome-brightgreen.svg)](CONTRIBUTING.md)


CoreKit is a modular Go toolkit designed to accelerate the development of REST APIs and backend services.

It provides a collection of reusable components and utilities commonly needed in modern applications, including authentication, configuration management, validation, error handling, logging, pagination, caching, security, and HTTP helpers.

## Goals

* Reduce boilerplate code
* Promote clean architecture and best practices
* Provide reusable and framework-friendly components
* Improve consistency across projects
* Simplify backend development with Go

## Features

* Authentication and authorization helpers
* JWT utilities
* Request validation
* Standardized API responses
* Error handling
* Pagination helpers
* Configuration management
* Logging utilities
* Security helpers
* HTTP and middleware utilities
* Cache abstractions
* Extensible and modular design

## Philosophy

CoreKit is designed to be lightweight, modular, and easy to integrate. Each package can be used independently, allowing developers to adopt only the components they need.

## Status

CoreKit is actively developed and aims to provide a solid foundation for building scalable and maintainable Go backend applications.
